SmartCitizen is a web-based complaint and service request management system developed using ASP.NET Core. The platform enables citizens to raise issues or requests (such as potholes, electricity failures, or waste management problems) directly to government authorities. It promotes transparency, accountability, and faster resolution of public concerns.

Key Features:

User Dashboard – Citizens can submit complaints/requests, track their status, and receive updates.

Service Provider Role – Integrated within the user dashboard, allowing relevant authorities (e.g., road department, electricity board) to view and act on assigned tasks.

Admin Dashboard – Government administrators can monitor all complaints, assign them to service providers, and mark them as completed.

Complaint Tracking – Real-time status updates from submission to resolution.

Report Management – Admin can generate reports to analyze issue trends and performance.

Authentication & Roles – Secure identity-based system with distinct roles for Users, Service Providers, and Admin.

Technical Implementation:

Backend: ASP.NET Core MVC with Entity Framework for data access.

Frontend: Admin dashboard designed using AdminLTE, while user dashboards are custom-built for simplicity and usability.

Database: SQL Server to store user data, complaints, and service workflows.

Architecture: Organized into areas (Admin, User, Report) with controllers for modular and maintainable development.

Purpose:

The goal of SmartCitizen is to bridge the gap between citizens and government authorities by providing a digital platform for managing complaints efficiently. It encourages citizen participation, government accountability, and smarter urban management. The project demonstrates the application of full-stack .NET development skills with a real-world social impact.
